# 🔍 mb_inspector

> Versão final do utilitário de inspeção e diagnóstico de equipamentos em rede local, com foco em segurança eletrônica (câmeras IP, NVRs/DVRs, servidores, etc.).

## 📌 Sobre o Projeto
O **mb_inspector** foi desenvolvido para automatizar a análise e identificação de dispositivos de segurança eletrônica na rede local. A ferramenta diferencia automaticamente câmeras, servidores e equipamentos diversos, oferecendo uma interface e fluxo simples para leitura, validação e exportação de dados.

## ⚙️ Pré-requisitos
Para o correto funcionamento de todas as funcionalidades de varredura e inspeção, é necessário ter o **Nmap** instalado no ambiente Windows.

* **Nmap para Windows:** Baixe e instale o executável oficial em [nmap.org/download.html](https://nmap.org/download.html).
* **python para Windows:** Baixe e instalei o executável oficial em

https://www.python.org/downloads/windows/

## 🚀 Principais Funcionalidades
* **Inspeção e Identificação:** Reconhecimento e categorização de dispositivos de segurança eletrônica (câmeras, servidores, etc.).
* **Varredura e Mapeamento:** Integração com Nmap para identificação precisa de portas e serviços na rede local.
* **Validação de Integridade:** Verificação automática de inconsistências nos dispositivos encontrados.
* **Relatórios:** Geração de logs e exportação de dados estruturados para análise.

## 🛠️ Tecnologias Utilizadas
